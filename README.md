# MoaPlan · 모아플랜

단체의 활동 기획, 후보지 관리, 일정 연동과 Instagram 홍보물 제작·게시를 돕는 웹 서비스입니다. 활동별 홍보뿐 아니라 단체 소개·회원 모집 등 독립적인 단체 홍보도 만들 수 있습니다.

- 운영 서비스: https://moaplan.pages.dev
- 저장소: https://github.com/nappeni/MoaPlan
- 작업 인계 및 변경 기록: [docs/HANDOFF.md](docs/HANDOFF.md)
- 아래 기능과 운영 상태는 2026-09-13 기준입니다.

## 메뉴와 주요 기능

### 활동 기획

- 활동을 목록·달력으로 확인하고 새 기획을 작성·편집합니다.
- 활동명, 분류, 작성 템플릿, 참석 가능 등급, 진행 상태를 관리합니다.
- 시작·종료 날짜와 시간, 신청 마감, 모집 정원, 봉사 인증 시간, 참가 신청 URL을 입력합니다.
- 저장된 후보지를 선택하거나 활동 장소·주소, 공동 이동 집합 장소·시간을 작성합니다.
- 기획 메모, 공지 본문, 참고 링크, 첨부 이미지와 이미지 표시 위치를 관리합니다.
- AI로 작성 내용을 제안받고 검토한 후 반영할 수 있습니다. 외부 AI 키와 모델 설정이 필요합니다.
- 공지 미리보기와 복사, 기존 활동 재사용 및 삭제를 지원합니다.
- 기획 확정 후 Google Calendar 반영 및 활동 홍보 게시를 진행합니다. 날짜·시간의 선후 관계를 검증합니다.
- 기획이 바뀌면 기존 홍보물과 연결 일정의 갱신 필요 상태를 표시합니다.

### 후보지 관리

- 후보지 이름, 담당자와 연락처, 협의 상태, 주소와 상세 주소·우편번호를 관리합니다.
- 마지막 연락일, 다음 연락 예정일, 활동 가능 조건 등을 기록하고 활동 기획에 연결합니다.
- 주소 검색을 지원합니다.
- 작성·수정 중에는 새 등록 버튼을 숨기며, `목록` 버튼으로 목록에 돌아갑니다.

### 단체 홍보

활동 기획과 별개로 단체 소개, 회원 모집, 홍보 캠페인용 피드를 준비합니다. 단체 홍보는 활동·캘린더 데이터와 분리하여 저장합니다.

- 홍보 제목과 단체 소개·홍보 목적·컨셉을 입력합니다.
- `입력 내용 저장`은 AI 호출 없이 입력 내용을 저장합니다.
- `AI 홍보 초안 만들기`는 입력 내용을 바탕으로 이미지 구성, 문구, 캡션과 해시태그를 제안합니다.
- 목적·컨셉을 수정하고 `AI 초안 다시 만들기`로 새 제안을 받을 수 있습니다.
- 생성된 제안은 검토본이며 초안 저장 시 반영됩니다. AI 요청 실패 시 입력과 기존 저장본을 유지합니다.
- 입력 내용만 변경해 저장한 경우 기존 홍보물을 재검토하도록 표시합니다.

### 홍보 이미지 편집 — 활동·단체 공통

- 표지를 포함해 최대 8장으로 구성합니다. 첫 장은 표지이며 다음 장부터 상세 내용을 배치합니다.
- 표지 제목·소개 문구, 각 장의 제목·본문과 배경 설명을 직접 수정합니다.
- 표지는 첫 위치를 유지하며, 상세 장은 추가·이동·삭제할 수 있습니다.
- 장별 AI 배경 생성, 직접 사진 업로드, 배경 제거를 지원합니다. 배경 생성은 문구 생성과 별도 작업입니다.
- 등록된 단체 로고가 있으면 로고만 표시하고, 로고가 없으면 단체명을 표시합니다. 로고 비율을 유지하며 표지에는 더 큰 영역을 사용합니다.
- 배경 이미지의 색감을 보존하며 밝기에 따라 글자색과 얇은 외곽선을 적용합니다.
- 텍스트는 배경 이미지에 생성하지 않고 편집 가능한 문구로 합성합니다. 글이 넘치면 내용을 줄이거나 장을 나누도록 안내합니다.
- 현재 장 다운로드, 게시용 전체 이미지 생성·저장, 저장된 피드 미리보기를 제공합니다.
- `게시용 N장 생성·저장`은 이미지 업로드 후 현재 홍보 초안까지 함께 저장합니다. 이미지 합성과 압축은 AI 재생성 없이 실행됩니다.
- 기존에 저장한 게시용 이미지에 로고·레이아웃 변경을 반영하려면 게시용 이미지를 다시 생성·저장해야 합니다.

### Instagram 수동 게시

1. 단체 관리에서 Instagram 연결 정보를 저장하고 연결 테스트를 실행합니다.
2. 홍보 이미지와 캡션·해시태그를 작성합니다. 활동 홍보는 기획 확정이 필요합니다.
3. `게시용 N장 생성·저장`으로 최종 이미지와 초안을 저장합니다.
4. 저장된 피드와 대상 계정을 확인하고 게시 동의에 체크합니다.
5. `Instagram에 게시`를 눌러 게시를 요청합니다.
6. 화면에서 진행 결과를 확인합니다. 필요하면 `게시 상태 확인`을 누릅니다.

게시 버튼은 연결 설정 누락, 미확정 활동, 이미지 부족, 저장하지 않은 변경, 재검토 필요, 동의 누락 또는 이미 진행·완료된 요청이 있으면 비활성화되며 이유를 안내합니다.

- Instagram Login 방식의 프로페셔널 계정용 API를 사용합니다.
- 숫자 형식의 **Instagram 사용자 ID**, 게시 권한이 있는 **액세스 토큰**, **Graph API 버전**을 설정합니다. 사용자명·앱 ID·앱 시크릿은 게시용 토큰의 대체값이 아닙니다.
- 계정 연결 조회 성공만으로 실제 게시 권한과 모든 게시 조건이 검증되는 것은 아닙니다.
- 이미지 준비, 다중 이미지 구성, 게시 요청을 단계별로 처리하고 상태를 저장합니다.
- 게시 동의 사용자·시각·검토 버전을 기록합니다. 진행·완료 화면에서는 동의 완료 상태를 표시합니다. 새 홍보물에는 새 동의가 필요합니다.
- 오류 및 게시 완료를 안내합니다. 결과가 불명확하면 자동 재게시하지 않고 실제 Instagram 확인을 요청합니다.
- `게시 상태 확인`은 MoaPlan 서버에 저장된 최신 처리 결과를 조회합니다. 게시 후 Instagram에서 삭제된 게시물의 존재 여부를 별도로 검사하지는 않습니다.
- 수동 게시 처리 중에는 화면을 유지하세요. 닫았다면 해당 홍보물을 다시 열어 진행 상태를 확인합니다.
- 게시 완료 후 `새 홍보 만들기`로 기존 게시 이력을 보관하고 새 홍보물을 준비할 수 있습니다.

### 단체 관리와 외부 연결

| 구분 | 제공 기능 |
| --- | --- |
| 기본 정보 | 단체 정보, 로고 업로드, 대표 색상 선택·색상값 확인, 단체 데이터 내보내기 |
| 공지·홍보 기준 | 공지 및 홍보 작성에 사용할 단체별 기준 설정 |
| AI 설정 | API 키, 텍스트·이미지 모델 설정 및 연결 확인 |
| Instagram | 숫자 사용자 ID, 게시 토큰, API 버전 설정 및 연결 확인 |
| Google | OAuth 연결, 캘린더 조회·선택, 연결 해제 |
| 이미지 저장소 | R2 연결 설정 및 저장 이미지 사용량 안내 |

Google Calendar는 사용자의 버튼 동작으로 활동 일정을 등록·갱신하거나 연결된 일정을 삭제합니다. 단체 홍보는 캘린더에 등록하지 않습니다.

### 계정·저장·보안

- 로그인한 단체 범위로 활동, 후보지, 홍보물, 설정을 분리합니다.
- 외부 서비스 비밀 키는 암호화해 저장하고 전체 값을 다시 표시하지 않습니다. 기존 값 유지와 명시 삭제를 지원합니다.
- 로그인 요청 제한과 게시 작업의 중복 실행 방지 상태를 서버에서 관리합니다.
- 화면 새로고침 후 메뉴, 선택한 저장 항목, 설정 탭을 복원합니다. **저장하지 않은 편집 내용의 자동 복원 기능은 아닙니다.**
- 운영 데이터는 Supabase PostgreSQL, 이미지 파일은 R2에 저장합니다.

## 이미지 용량 관리

- 업로드 입력은 최대 15MB, 서버 처리 이미지 크기는 최대 16MP로 제한합니다.
- 이미지는 최대 1080×1350 범위로 축소하고 작은 원본을 확대하지 않습니다.
- 서버 JPEG는 약 180KiB를 목표로 압축하며 상한은 300KiB입니다. 투명 영역은 흰색으로 합성합니다.
- 썸네일은 160px WebP를 사용하며 원본 파일은 보관하지 않습니다.
- 게시용 캔버스는 1080×1350으로 합성합니다. AI 배경 생성과 게시용 이미지 합성은 별개입니다.

## 운영 구성

| 구성 요소 | 역할 |
| --- | --- |
| React 19 · Vite 6 | 관리자 화면과 이미지 편집 |
| Cloudflare Pages · Pages Functions | 정적 화면 호스팅과 API 프록시 |
| Supabase Edge Functions | API 실행, 인증·단체 데이터 처리, 외부 연동 |
| Supabase PostgreSQL | 단체별 상태 데이터와 작업 진행 상태 저장 |
| Cloudflare R2 | 최적화된 이미지 저장 |
| OpenAI API | 문구 구성 및 배경 이미지 생성 |
| Instagram API · Google Calendar API | 명시적 게시 및 일정 연동 |

현재 Pages + Supabase Edge Functions 배포를 사용합니다. Node/Express 실행 경로도 유지합니다. Node 이미지 처리는 Sharp, Edge 이미지 처리는 ImageMagick WASM을 사용합니다.

## 로컬 실행

Node.js 22.12 이상이 필요합니다.

```sh
npm ci --ignore-scripts
npm run dev:local
```

http://localhost:5173 에서 단체와 운영자 계정을 생성합니다.

`dev:local`은 프로젝트의 운영 `.env`를 읽지 않고 `.local/development/`에 별도 개발 데이터와 키를 저장하며 예약 작업을 끕니다.

```sh
# .env에 지정한 데이터 저장소와 연결해 실행
npm run dev

# 검증 및 프런트엔드 빌드
npm test
npm run build
```

`npm run dev`는 `.env` 설정에 따라 실제 Supabase 데이터에 연결할 수 있습니다. 운영 DB와 격리된 실험에는 `dev:local`을 사용하세요. 외부 서비스를 설정한 이후의 AI 생성·파일 업로드·게시·일정 등록은 실제 외부 작업이므로 구분해서 실행해야 합니다.

Node 서버 배포는 빌드 후 `NODE_ENV=production` 환경에서 `npm start`를 사용합니다. 환경변수 항목은 [.env.example](.env.example)을 참고하세요. `.env`, `.local/`, 로컬 인증 정보와 빌드 산출물은 Git에서 제외합니다. 비밀 키를 README나 로그에 넣지 않습니다.

## 검증과 현재 제한

- 자동화 테스트는 단체 격리, 암호화, 버전 충돌, AI 실패 시 데이터 보존, 표지 순서, 이미지 압축, 프록시, 게시 동의, 단계별 게시와 중복 방지 등을 검증합니다.
- 2026-09-13 기준 테스트 28개와 프런트엔드 빌드가 통과했습니다. 자동화 테스트는 모의 외부 서비스와 격리 데이터를 사용하며 실제 Instagram 게시를 수행하지 않습니다.
- **자동 예약 게시 기능은 현재 비활성화되어 있습니다.** 예약 처리 코드와 설치된 Cron은 있지만 운영 Cron은 중지되어 있고 Edge worker도 비활성입니다. 현재 사용 흐름은 관리자 수동 게시입니다.
- AI 문구·배경 생성에는 외부 API 비용이 발생합니다. 필요한 키가 없거나 요청에 실패하면 오류를 표시하며 생성·게시 성공으로 처리하지 않습니다.
- 토큰 만료, 계정 권한, 외부 서비스 장애 등은 연결·게시 결과에 영향을 줍니다.
- 회원 명부 및 회비 납부 관리는 현재 범위에 포함하지 않습니다.
- 세부 배포 이력과 과거 제한은 [HANDOFF](docs/HANDOFF.md)에 시간순으로 누적되어 있습니다. 최신 기록을 먼저 확인하세요.
